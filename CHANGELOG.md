# Changelog

## 0.1.0 – unreleased

- First version for Windows, the counterpart of the macOS menu bar app, built with WinUI 3: time
  entries with project, task, description and duration, the timer, attendance with corrections,
  and several companies work as on the Mac. A clock icon in the notification area of the taskbar
  opens the window above it; a green dot on the icon shows a running timer, the tooltip lists
  today's times, and the right-click menu stops and books the running timer without opening the
  window. Settings open in a window of their own. The version from GitHub starts with Windows and
  checks for updates once a day; the Microsoft Store version leaves both to the user and the Store.
